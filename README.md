# 🍔 맘스터치 칼로리 분석기

## 1. 프로젝트 소개
맘스터치 메뉴의 칼로리를 검색하고 비교할 수 있는 웹앱입니다.

## 2. 개발 목적
패스트푸드를 주문할 때 메뉴별 칼로리를 쉽게 확인하고
자신의 목표 칼로리에 맞는 음식을 선택할 수 있도록
돕기 위해 제작했습니다.

## 3. 주요 기능
- 맘스터치 메뉴 검색
- 메뉴별 칼로리 확인
- 메뉴 사진 표시 (사진 등록 시)
- 메뉴별 칼로리 비교 그래프
- 여러 메뉴의 총칼로리 계산
- 목표 칼로리 이하 메뉴 추천
- 잘못된 입력에 대한 예외 처리

## 4. 사용 기술
- Python
- Streamlit
- Pandas
- GitHub

## 5. 실행 방법
1. requirements.txt의 라이브러리를 설치합니다.
2. app.py와 menu_data.csv를 같은 폴더에 저장합니다.
3. 다음 명령어를 실행합니다.

streamlit run app.py

## 6. 데이터 출처
맘스터치 메뉴의 칼로리 정보는 참고용 자료를 사용했습니다.
실제 제품의 최신 영양정보와 차이가 있을 수 있습니다.

## 7. 프로젝트의 한계점
- 일부 메뉴의 칼로리 정보가 없을 수 있습니다.
- 신메뉴가 자동으로 추가되지 않습니다.
- 메뉴 사진이 등록되지 않은 경우 표시되지 않습니다.

## 8. AI 활용
프로젝트 개발 과정에서 ChatGPT를 활용하여
파이썬 코드 작성 방법과 오류 해결 방법을 참고했습니다.
